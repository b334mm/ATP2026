# Resumo 
## Resumo

Criação de um jogo em Python: "Adivinha o número", com duas modalidades: 
1. *O utilizador adivinha*: o cumputador escolhe um número aleatório de 0 a 100 e o jogador tenta adivinhar.
2. *O computador adivinha:* o jogador pensa num número entre 0 e 100 e o computador usa pesquisa binária para o descobrir, tentando, assim, sempre o valor do meio do intervalo que ainda resta.

Em ambas as modalidades, o programa termina quando o número é descoberto e mostra o número de tentativas utilizadas. O programa valida também as entradas do jogador.
